# web · 山野咖啡品牌官网 + 会员中心

Vue 3 + Vite + TypeScript。

## 启动

```bash
npm install
npm run dev        # http://127.0.0.1:5302（/api 代理到 server 3300）
```

其他命令：

```bash
npm run build      # 类型检查 + 构建
npm run typecheck  # TypeScript 类型检查
npm test           # 单元测试（vitest）
```

## 默认账号

会员中心使用手机号 + 验证码登录（测试验证码固定 `123456`），首次登录自动注册。

## 页面

| 页面 | 路径 | 说明 |
|-|-|-|
| 首页 | / | 品牌主视觉、当季推荐、门店入口 |
| 菜单 | /menu | 按分类浏览商品，点击查看规格 |
| 门店 | /stores | 门店列表与营业状态 |
| 品牌故事 | /story | 品牌故事与理念（自绘 SVG 插画） |
| 会员中心 | /member | 订单、积分、等级、优惠券（需登录） |
| 登录 | /login | 手机号 + 验证码登录 |

## 技术要点

- 品牌主题变量见 `src/style.css`（与 admin / miniapp 共用品牌色）。
- 响应式导航：手机端折叠为汉堡菜单；390 / 768 / 1440 宽度无横向滚动。
- 插画与图标均为自绘 SVG，不引用外部资源。
- 统一响应 `{"code":0,"data":..,"message":"ok"}`，金额整数分、时间 UTC ISO8601、手机号脱敏。
- 会员中心路由守卫：未登录访问 /member 跳转登录页。

## 已知问题

- 需要 server（端口 3300）同时运行才能正常调用接口。
- 会员验证码固定 123456，仅模拟短信。
