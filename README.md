# 山野咖啡 · 门店点单平台

> 虚构品牌，门店、地址、商品、价格和会员均为示例数据，仅用于 AI 编程实测。

本仓库由 LongCat 2.5 Preview（美团）通过 pi 编程助手完成，需求见 `docs/brief.md`，任务见 `todo/`。

- 提交作者 `longcat-2.5-preview`：模型自己的提交
- 提交作者 `host`：主持者的初始化或人工介入

| 目录 | 内容 | 技术栈 |
|-|-|-|
| `server/` | API 服务 | Node.js + TypeScript + Fastify + SQLite |
| `admin/` | 后台管理 | React + shadcn/ui（Base UI）+ Tailwind CSS v4 |
| `web/` | 品牌官网与会员中心 | Vue 3 + Vite |
| `miniapp/` | 点单小程序 | uni-app（编译到微信小程序） |

## 功能概览

- 会员：手机号 + 验证码登录（模拟短信）、积分（每消费 1 元积 1 分）、等级（银卡/金卡/黑卡自动升级）、优惠券
- 点单：门店选择、分类商品、规格选择（杯型/温度/糖度）、购物车、自提/堂食、优惠券默认最优、模拟支付
- 活动：第二杯半价（后台可配置时间范围与适用商品，先活动后券计价）
- 订单：取餐码、状态进度（待支付→已支付→制作中→待取餐→已完成）、后台状态推进
- 后台：数据看板、商品/订单/门店/会员/优惠券/活动管理、账号与角色权限

## 全局约定

- API 统一返回 `{"code":0,"data":...,"message":"ok"}`，错误码登记见 `server/docs/errors.md`
- 金额一律整数“分”，界面格式化为 `¥xx.xx`
- 时间一律 UTC ISO8601 存储与传输，界面按北京时间显示
- 手机号在列表、日志、非本人接口中脱敏为 `138****1234`
- 不依赖外部图片或 CDN，插画与图标均为自绘 SVG / CSS
- 三个前端共用一套品牌视觉（深林绿 + 暖米 + 焦糖）

## 已知问题

- 会员验证码固定为 `123456`，仅模拟短信，无真实下发。
- 支付为模拟支付，无真实支付渠道。
- 门店电话为公开营业电话，未脱敏；会员手机号在后台订单列表等接口中脱敏。
- admin / web 需要 server（端口 3300）同时运行才能正常调用接口。
- admin 构建产物单 chunk 较大（含 Recharts），未做代码分割。
- miniapp 依赖安装必须使用 `--legacy-peer-deps`（uni-app 的 peer 声明与 Vue 3 冲突，实际运行无影响）。
- 活动类型目前固定为「第二杯半价」，未扩展为多种活动类型；后续如需其他活动需扩展 `promotions` 表与计价服务。
