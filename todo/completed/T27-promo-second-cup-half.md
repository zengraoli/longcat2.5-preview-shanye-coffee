# T27 第二杯半价活动

阶段：S4
状态：已完成（v0.29，2026-09-30）

## 要做什么
新增"第二杯半价"活动：
- 后台可配置活动的开始时间、结束时间和适用商品；
- server 负责计价：同一订单中同一适用商品的第 2、4、6… 杯按半价计算（半价向下取整到分）；与优惠券叠加时先算活动价再用券（券的门槛判断与优惠金额基于活动后金额）；
- 小程序与官网的价格展示体现活动价（适用商品打"第二杯半价"标签）；
- 小程序下单金额（确认订单、订单详情）体现活动优惠；
- 后台订单明细显示活动优惠金额。

## 完成标准
- 后台可创建 / 编辑 / 停用活动，配置起止时间与适用商品
- 同一订单中适用商品第 2、4… 杯半价，金额明细与 server 计算一致（含与优惠券叠加顺序：先活动后券）
- 小程序点单 / 确认订单 / 订单详情、官网菜单页展示活动价
- 后台订单明细显示活动优惠金额
- 相关构建、类型检查、测试全部通过
