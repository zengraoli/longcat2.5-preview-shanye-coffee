山野咖啡 · API 文档

Base URL: /api · 统一响应格式: {"code": 0, "data": ..., "message": "ok"}

鉴权

受保护接口需在请求头携带 Authorization: Bearer <token>

会员端接口

POST/api/member/login

手机号 + 验证码登录（验证码固定 123456）

GET/api/stores

门店列表（含营业状态）

GET/api/stores/:id

门店详情

GET/api/categories

商品分类列表

GET/api/products

商品列表（?categoryId=筛选，仅返回上架商品）

GET/api/products/:id

商品详情（含规格与价格）

GET/api/member/me

当前会员信息（积分、脱敏手机号）

GET/api/coupons

可领取的优惠券列表

POST/api/coupons/:id/claim

领取优惠券

GET/api/my/coupons

我的优惠券列表

POST/api/coupons/best

计算最优优惠券（body: {"amount": 金额分}）

POST/api/orders

创建订单（自提/堂食，含规格与优惠券）

GET/api/orders

我的订单列表（?status=筛选）

GET/api/orders/:id

订单详情

POST/api/orders/:id/pay

模拟支付

POST/api/orders/:id/cancel

取消订单（仅支付前可取消）

GET/api/member/points-logs

积分明细

后台管理接口

POST/api/admin/login

后台账号密码登录

PATCH/api/admin/products/:id/statusadmin

商品上下架（body: {"status": "on/off"}）

PATCH/api/admin/products/:id/sold-outadmin

商品售罄切换（body: {"soldOut": true/false}）

GET/api/admin/ordersadmin/staff

订单列表（店员仅本门店）

POST/api/admin/orders/:id/statusadmin/staff

推进订单状态（paid → making → ready → completed）
