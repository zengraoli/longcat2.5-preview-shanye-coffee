# 错误码登记

所有接口统一返回 `{"code": 0, "data": ..., "message": "ok"}`；出错时 `code` 非 0，`message` 为中文原因，`data` 为 `null`。

| code | HTTP | 含义 | 触发场景 |
|-|-|-|-|
| 1000 | 500 | 服务器内部错误 | 未捕获异常 |
| 1001 | 400 | 参数错误 | 请求参数缺失、格式非法或类型错误 |
| 1002 | 404 | 资源不存在 | 接口或记录不存在 |
| 1003 | 401 | 未登录或登录已过期 | 缺少 / 无效 / 过期 token |
| 1004 | 403 | 无权限 | 角色不足，如店员访问管理员接口 |
| 1005 | 409 | 状态冲突 | 重复操作、账号已存在等 |
| 2001 | 400 | 手机号格式错误 | 登录时手机号非法 |
| 2002 | 400 | 验证码错误 | 会员登录验证码不正确 |
| 2003 | 400 | 账号或密码错误 | 后台登录凭据错误 |
| 2004 | 401 | 登录已过期 | token 超过有效期 |
| 3001 | 404 | 门店不存在 | 门店 ID 无效 |
| 3002 | 404 | 商品不存在 | 商品 ID 无效 |
| 3003 | 400 | 商品已下架 | 购买下架商品 |
| 3004 | 400 | 商品已售罄 | 购买售罄商品 |
| 3005 | 400 | 门店休息中 | 在休息中的门店下单 |
| 4001 | 404 | 优惠券不存在 | 券 ID 无效 |
| 4002 | 409 | 优惠券已领取 | 重复领取同一券 |
| 4003 | 400 | 优惠券已过期 | 使用超出有效期的券 |
| 4004 | 400 | 优惠券不可用 | 券已停用、已领完或不满足使用条件 |
| 5001 | 404 | 订单不存在 | 订单 ID 无效 |
| 5002 | 400 | 订单状态不允许该操作 | 非法状态流转 |
| 5003 | 403 | 订单不属于该门店 | 店员操作他店订单 |
| 5004 | 400 | 订单商品无效 | 商品为空 / 下架 / 售罄 / 规格非法 |
| 5005 | 403 | 优惠券不属于该会员 | 使用他人领取的优惠券 |
| 6001 | 404 | 会员不存在 | 会员 ID 无效 |
